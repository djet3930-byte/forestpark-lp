# 採用特化ページ 設計書

作成日: 2026-08-13
対象: ばななケアラウンド（株式会社 FOREST PARK）採用ページ

## 目的

既存の利用者・関係機関向けLP（`index.html`）とは別に、求職者向けの採用専用ページ `recruit.html` を新設する。訪問介護の人材確保を目的とし、応募のハードルを下げる導線を複数用意する。

## 構成方針

既存 `index.html` と同じ「単一HTML・スタイル内包」構成を踏襲する。共通CSSの外部ファイル化は行わない。2ページ構成では分割の保守メリットが小さく、既存LPへの変更リスクだけが増えるため。

配色（`--cream` / `--banana` / `--ink` 等のカスタムプロパティ）、フォント（Noto Serif JP / Noto Sans JP / Archivo）、スクロール連動アニメーション、モバイル固定CTAバーの挙動は既存から継承する。

ヒーローは画像ではなくタイポグラフィ主体で構成する。`assets/kv.jpg` は利用者向けのキービジュアルであり、採用文脈へ流用すると訴求がぼやけるため。採用向け写真が用意され次第、差し込める構造にしておく。

## レビュー反映（2026-08-13）

技術監査と労務・採用広報レビューを実施し、以下を修正した。

**法令対応**
- 無資格者が生活援助に従事できると読める記述を全面修正。訪問介護は初任者研修修了以上が必要であり、生活援助も例外ではない
- 受動喫煙防止措置の行を募集要項に追加（職安法の必須明示事項）
- 契約期間・更新の判断基準・更新上限、就業場所と業務内容の「変更の範囲」を追加（令和6年4月改正）
- 移動時間を「移動手当1件100円」ではなく労働時間として賃金を支払う旨に変更
- 加入保険を労災・雇用・健保厚年に分け、適用要件を明示
- 賃金締切日・支払日・深夜割増、休憩・所定時間外労働を追加
- 通院等乗降介助の免許要件の記述を修正（第二種免許・大臣認定講習の要否を要確認コメント化）
- 職場体験での利用者宅同行に、利用者本人の同意が前提である旨を明記

**裏付けのない記述の排除**
- 在籍スタッフの経歴・構成比を事実として述べる記述をすべて非断定形へ（「こんな経歴の方が働いています」→「こんな方に向いています」等）
- 「長距離の運転はありません」と訪問対応エリアの矛盾を解消

**UX・技術**
- 「見学だけ」導線が必須5項目に阻まれていた問題を解消（見学チェックをフォーム冒頭へ移動、保有資格・経験を任意化）
- 必須 select にプレースホルダー option を追加し、required を実効化
- 見出しレベルの飛び（h2→h4）を解消。h4 は 0 件
- 募集要項テーブルに視覚的非表示の caption を追加
- 未使用の `.mincho` を削除

## 品質基準

- 既存LPと同一のアクセシビリティ水準（focus-visible、prefers-reduced-motion、aria属性）
- モバイルファースト。760px以下でのレイアウト崩れがないこと
- 求人媒体ではなく自社採用ページとして、労働条件の記載が誤解を生まない表現であること
- 職業安定法の観点から、確定していない条件を断定的に書かない
